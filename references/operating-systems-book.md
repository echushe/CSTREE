# Operating Systems Three Easy Pieces

## Primary sources

- [Author-hosted book and free chapters](https://pages.cs.wisc.edu/~remzi/OSTEP/)

## Contribution and scope

OSTEP organizes operating systems around virtualization, concurrency, and persistence. It is an implementation-oriented anchor for scheduling, address spaces, locks, file systems, and crash behavior. Particular system-call and storage guarantees still require platform documentation.

## Reading route

Read processes and CPU scheduling, then address translation, then threads and synchronization. Continue to files and persistence. Use the exercises to connect each abstraction to an observable program.
