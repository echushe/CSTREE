## Contribution and scope

These primary sources distinguish language rules from implementation and host behavior. Specifications are normative for their stated editions; tutorials and the C++ Core Guidelines explain usage and are not substitutes for a standard. N1570 is an explicitly older C11 draft. Rolling documentation can change.

## Reading route

Choose one language and test assignment, aliasing, error handling, resource cleanup, and concurrency with tiny programs. Check the documented language or compiler version when a result depends on a feature or an implementation.
