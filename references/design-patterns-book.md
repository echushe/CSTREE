# Design Patterns Elements of Reusable Object-Oriented Software

## Primary sources

- [Publisher record and catalog contents](https://www.informit.com/store/design-patterns-elements-of-reusable-object-oriented-9780201633610)

## Contribution and scope

The Gang of Four catalog provides 23 patterns grouped by creational, structural, and behavioral purpose. The publisher records publication in October 1994. It supplies a shared vocabulary for recurring object-oriented designs, not a universal prescription for architecture or every language.

## Reading route

Start from one concrete problem: constructing a valid object, adapting an interface, or swapping behavior. Read intent, applicability, and consequences together. Compare a pattern-based version with an ordinary function or direct implementation in your chosen language.
