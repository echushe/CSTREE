# Software Engineering and Git Guides

## Primary sources

- [Software Engineering at Google](https://abseil.io/resources/swe-book/html/toc.html)
- [Pro Git second edition](https://git-scm.com/book/en/v2)

## Contribution and scope

Software Engineering at Google discusses maintaining code over time, including review, testing, dependencies, builds, and integration. Pro Git explains Git's model and collaboration workflows. Organizational examples should be adapted to the size and constraints of the project.

## Reading route

Read the testing and code-review material alongside a small change you can review. Use Pro Git to connect working tree, staging, commits, branches, and merging. Then follow one change from requirement through build, review, and release.
