# Introduction to Algorithms

## Primary sources

- [Publisher and fourth edition contents](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/)

## Contribution and scope

A standard reference for analysis, data structures, graph algorithms, greedy methods, and dynamic programming. The fourth edition was published in 2022. This is a broad textbook anchor, not a claim that the book introduced each linked idea.

## Reading route

Start with growth rates and invariants, then elementary structures and sorting. Follow with graph traversal and the contrasting proof styles of greedy methods and dynamic programming. Work small examples before reading a full proof.
